01

Selecionando Elementos (Queries)

1.1 Seletor por ID

Crie um parágrafo com id="mensagem" e um botão. Ao clicar no botão, use getElementById para exibir no console o texto do parágrafo.

💡 Dica: document.getElementById('mensagem').textContent
1.2 Seletor por Classe

Crie três divs com a classe caixa. Use getElementsByClassName para contar quantas caixas existem e exiba o número em um alerta.

💡 Dica: getElementsByClassName retorna uma HTMLCollection (array-like) — use .length para contar.
1.3 querySelector e querySelectorAll

Crie uma lista <ul> com 5 itens <li>. Usando querySelector, selecione o primeiro item e mude a cor do texto para vermelho. Usando querySelectorAll, selecione todos os itens e adicione uma borda pontilhada em cada um.

💡 Dica: querySelectorAll retorna uma NodeList — use .forEach() para iterar.
1.4 Seleção por Nome de Tag

Crie vários botões com <button>. Use getElementsByTagName para adicionar um evento de clique a todos os botões de uma só vez (cada clique exibe "Botão clicado" no console).

💡 Dica: Converta a HTMLCollection com Array.from() antes de usar .forEach().
02

Manipulação de Documento HTML

2.1 innerHTML vs textContent

Crie uma div vazia. Tenha dois botões: um que insere <strong>texto em negrito</strong> via innerHTML, e outro que insere o mesmo texto via textContent. Observe a diferença de comportamento.

💡 Dica: innerHTML interpreta as tags HTML; textContent trata tudo como texto puro.
2.2 Alterar Atributos (src de imagem)

Coloque uma imagem com id="foto" e dois botões: "Ligar" e "Desligar". Ao clicar em "Ligar", mude o src para uma imagem de lâmpada acesa; ao clicar em "Desligar", mude para apagada.

💡 Dica: Use element.setAttribute('src', url) ou element.src = url diretamente.
2.3 Manipular Classes CSS

Crie um quadrado vermelho com class="quadrado". Usando JavaScript, adicione uma classe borda-azul que adiciona borda azul de 3px. Depois, faça um botão que alterna (toggle) essa classe a cada clique.

💡 Dica: element.classList.toggle('borda-azul') faz o toggle automaticamente.
2.4 Estilos Inline

Crie um botão que, quando clicado, aumenta o tamanho da fonte de todo o corpo da página em 2px a cada clique (estilo inline).

💡 Dica: Leia document.body.style.fontSize, converta com parseInt(), some 2 e reaplique com 'px'.
03

Manipulação de Elementos (Criar, Remover, Clonar)

3.1 Criar e Adicionar Elemento

Crie uma lista ordenada vazia <ol id="minhaLista">. Um campo de texto e um botão "Adicionar". Ao clicar, pegue o valor do campo e adicione um novo <li> com esse texto ao final da lista. Limpe o campo após adicionar.

💡 Dica: document.createElement('li') e lista.appendChild(novoItem).
3.2 Remover Elemento Específico

Partindo do exercício anterior, adicione ao lado de cada <li> um botão "Remover" que, ao ser clicado, remove aquele item da lista.

💡 Dica: O botão precisa ser criado junto com o li. Use li.remove() ou pai.removeChild(li).
3.3 Clonar Elemento

Crie um card (div com imagem, título e texto) com id="cardOriginal". Um botão "Duplicar" que clona esse card e insere o clone logo abaixo do original. O clone deve ser funcional.

💡 Dica: element.cloneNode(true) — o argumento true clona também todos os filhos.
3.4 Substituir Elemento

Crie uma div com um texto qualquer. Um botão que substitui o conteúdo dessa div por um novo parágrafo criado dinamicamente com um texto diferente.

💡 Dica: pai.replaceChild(novoElemento, elementoAntigo) ou element.replaceWith(novo).
04

Eventos e Interação – Mouse

4.1 click

Crie uma caixa colorida. Ao clicar nela, exiba um alerta: "Você clicou na caixa".

💡 Dica: element.addEventListener('click', () => alert('...'))
4.2 mouseenter e mouseleave

Crie um quadrado que muda de cor quando o mouse entra (mouseenter) e volta à cor original quando sai (mouseleave).

💡 Dica: Guarde a cor original em uma variável antes de alterar.
4.3 dblclick

Crie um botão que, ao ser clicado duas vezes, altera o texto dele para "Duplo clique detectado!" e depois de 1 segundo volta ao texto original.

💡 Dica: setTimeout(() => botao.textContent = original, 1000) para reverter.
4.4 mousemove

Crie um pequeno retângulo que exibe as coordenadas X e Y do mouse dentro dele (atualizando em tempo real em um <span> ao lado).

💡 Dica: Use event.offsetX e event.offsetY para coordenadas relativas ao elemento.
05

Eventos e Interação – Teclado

5.1 keydown – Exibir Tecla Pressionada

Crie um campo de texto <input>. Ao digitar qualquer tecla, exiba no console o valor da tecla pressionada (use event.key).

💡 Dica: input.addEventListener('keydown', (e) => console.log(e.key))
5.2 keyup – Contador de Caracteres

Crie uma textarea com um limite de 140 caracteres. Mostre um contador regressivo abaixo que atualiza a cada keyup, indicando quantos caracteres ainda podem ser digitados.

💡 Dica: Calcule: 140 - textarea.value.length. Considere usar maxlength no HTML também.
5.3 Impedir Teclas Específicas

Crie um campo de texto que só aceite números. Use keydown para impedir que letras ou símbolos sejam digitados (event.preventDefault).

💡 Dica: if (!/^[0-9]$/.test(e.key) && e.key !== 'Backspace') e.preventDefault()
5.4 Atalho de Teclado – Enter

Crie um campo de texto e um botão de busca. Ao pressionar a tecla "Enter" dentro do campo, dispare a mesma ação que o botão (exibir um alerta com o texto digitado).

💡 Dica: if (e.key === 'Enter') buscar() — extraia a lógica em uma função para reutilizar.
06

Desafios Combinados

6.1 Lista de Tarefas (To-Do)

Crie um app de tarefas com: campo de texto + botão "Adicionar"; cada tarefa como <li> com texto e botão "Concluir"; ao concluir, aplicar text-decoration: line-through; botão "Remover todas concluídas" que remove as tarefas riscadas. Use querySelectorAll, eventos de clique, manipulação de classes e criação/remoção de elementos.

💡 Dica: querySelectorAll('li.concluida').forEach(li => li.remove())
6.2 Drag & Drop Simplificado com Mouse

Crie um quadrado que possa ser arrastado dentro de um contêiner maior. Eventos: mousedown, mousemove, mouseup. Atualize a posição (top/left) do quadrado conforme o movimento do mouse. (Não use HTML5 drag-and-drop; implemente manualmente.)

💡 Dica: No mousedown salve o offset cursor-elemento. No mousemove atualize top/left. No mouseup pare de mover. Use position: absolute no quadrado e position: relative no contêiner.
6.3 Editor de Teclas Especiais

Crie uma div editável (contenteditable="true"). Mostre um painel ao lado com: Ctrl+B → negrito, Ctrl+I → itálico, Ctrl+U → sublinhado.

💡 Dica: Use keydown detectando e.ctrlKey && e.key === 'b'. document.execCommand('bold') ainda funciona para fins de estudo. Lembre de e.preventDefault() para não acionar atalhos do navegador.
6.4 Galeria de Imagens Dinâmica

Crie um array de URLs de imagens. Exiba uma miniatura da primeira imagem. Botões "Próximo" e "Anterior" que trocam a imagem principal. Adicione também um campo de texto para adicionar uma nova URL à galeria (dinamicamente). Use manipulação de DOM, eventos de clique e seleção de elementos.

💡 Dica: Use um índice atual (let index = 0) e garanta que ele não ultrapasse os limites do array (0 e array.length - 1).
