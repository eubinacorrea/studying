# 📄 Exercícios de JavaScript DOM

Coleção de exercícios práticos para aprendizado de manipulação do DOM com JavaScript puro.

## Sobre

Este material foi gerado com auxílio de **Inteligência Artificial (Claude, da Anthropic)** com fins exclusivamente educacionais. Os exercícios cobrem os principais conceitos de manipulação do DOM e são voltados para quem está aprendendo JavaScript no front-end.

## Conteúdo

| # | Tema |
|---|------|
| 1 | Selecionando elementos (`getElementById`, `querySelector`, etc.) |
| 2 | Manipulação de conteúdo, atributos e estilos |
| 3 | Criar, remover e clonar elementos |
| 4 | Eventos de mouse (`click`, `mouseenter`, `mousemove`…) |
| 5 | Eventos de teclado (`keydown`, `keyup`, `preventDefault`…) |
| 6 | Desafios combinados (To-Do, Drag & Drop, Galeria…) |

São **24 exercícios** no total, com dicas de implementação em cada um.

## Arquivos

- `exercicios_dom_javascript.html` — versão interativa com progresso e checkboxes

## Como usar

Abra o arquivo `.html` diretamente no navegador. Nenhuma instalação necessária.

Para cada exercício, crie um arquivo `.html` separado e implemente a solução do zero. O objetivo é praticar — evite copiar respostas prontas antes de tentar.

## Aviso

> Este conteúdo foi gerado por IA e pode conter imprecisões. Recomenda-se usar como ponto de partida para os estudos, sempre consultando a [documentação oficial do MDN](https://developer.mozilla.org/pt-BR/docs/Web/API/Document_Object_Model) para aprofundamento.
